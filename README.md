# 🏫 TGVIS (The Green Valley International School)

![Framer Motion](https://img.shields.io/badge/Framer_Motion-12-blue?style=for-the-badge&logo=framer)

The official web platform for **The Green Valley International School** (Bihta, Patna). This project is a highly optimized, interactive, and beautifully animated Next.js application designed to provide an immersive digital experience for students, parents, and faculty.

## ✨ Key Features
- **Immersive 3D Scroll Animations:** Powered by Framer Motion, featuring roller-diving transitions, holographic tilt effects, and hardware-accelerated fluid scroll logic.
- **Dynamic Routing & Architecture:** Built on Next.js App Router for optimal SEO and instantaneous page loads.
- **Interactive Campus Gallery:** High-performance responsive image grids with micro-interactions.
- **Glassmorphism UI:** Premium styling featuring fluid blurs, liquid glass containers, and neon glows.
- **Mobile-First Design:** Fully responsive layout with snap-scrolling and touch-optimized interfaces.

## 🛠️ Technology Stack
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Typography:** Geist Font Family (Optimized by Vercel)

## 🚀 Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
